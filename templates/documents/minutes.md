## 1. Minutes of the previous meeting

The minutes of 14 October were approved without changes. All actions are closed except the security review (see item 2).

## 2. Release 4.2 — status

Lena reported that the release is on track for **28 November**. Two of the nineteen features moved to release 4.3 because the supplier's API was late. The security review is planned for next week.

> [!NOTE]
> **Decision:** Release 4.2 goes ahead on 28 November with 17 features. The remaining two move to 4.3.

## 3. Customer feedback

Aisha presented the autumn survey (612 responses). Satisfaction rose to 8.1. The three most requested improvements are offline mode, faster search and exporting to PDF.

- The committee asked for a breakdown by customer size.
- Tom suggested inviting five customers to the next sprint review.

## 4. Budget for the mobile app

Marc presented two options: a native app (€240,000) or a progressive web app (€95,000). After discussion, the committee preferred to start with the web app and revisit native apps in a year.

> [!IMPORTANT]
> **Decision:** Approve €95,000 for a progressive web app, to be delivered in Q2 {{next_year}}.
